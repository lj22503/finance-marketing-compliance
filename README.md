# 金融营销合规助手 v2.0.0

> 基于《金融产品网络营销管理办法》及 15+ 金融监管法规，提供金融产品营销内容合规审查和方案生成。

---

## 解决什么问题？

| 现状 | 用合规助手 |
|------|----------|
| 写完文案不知道有没有违规 | 自动审查，标出具体违规条款 |
| 不确定这个说法是否合规 | 合规方案生成，告诉你怎么说才合规 |
| 不同产品规则不一样 | 分行业专属审查（存款/基金/保险/信托） |
| 不知道引用了哪些法规 | 自动标注违规条款和对应法规 |

---

## 4 核心功能

| 功能 | 命令 | 用途 |
|------|------|------|
| 文章合规审查 | `compliance-checker.py review` | 审查营销文章是否违规 |
| 营销方案审查 | `compliance-checker.py plan` | 审查完整营销方案 |
| 分行业审查 | `compliance-checker.py industry` | 按存款/基金/保险等行业专属规则 |
| 合规方案生成 | `compliance-checker.py generate` | 生成合规版本的营销方案 |

---

## 快速开始

```bash
# 文章合规审查
python3 scripts/compliance-checker.py review \
  --content "XX银行高收益存款产品推荐：年化收益5.8%，保本保息，限时抢购！" \
  --product-type "存款"

# 营销方案审查
python3 scripts/compliance-checker.py plan \
  --plan "通过公众号推文推荐XX基金，使用低风险高收益表述，附购买链接" \
  --channel "公众号" \
  --product-type "基金"

# 合规方案生成
python3 scripts/compliance-checker.py generate \
  --product-type "存款" \
  --target-audience "30-50岁工薪族" \
  --channel "微信公众号" \
  --selling-points "年化收益3.5%，期限灵活"
```

## FAQ

**Q：能保证100%合规吗？**

A：不能。本工具基于公开法规知识库提供参考意见，最终合规责任由持牌机构和投顾承担。

**Q：支持哪些产品类型？**

A：存款、基金、保险、信托全支持。不同产品适用不同规则，审查时会自动匹配。

**Q：法规更新了怎么办？**

A：更新 references/ 目录下的 regulations.md 文件即可，审查规则自动应用最新法规。

**Q：和投教工作流（investor-education-workflow）有什么区别？**

A：本工具专注"营销内容是否违规"，投教工作流专注"怎么说服和陪伴客户"。营销内容发布前先过合规审查，再走投教流程润色。

## ⚠️ 注意事项

1. **法规时效性**：始终使用最新法规版本
2. **违规判断**：标注具体违规条款，说明原因
3. **产品类型差异**：根据产品类型选择对应规则
4. **免责声明**：本工具仅供参考，不构成法律意见
